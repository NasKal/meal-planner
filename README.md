# Meal Planner

Προσωπική εφαρμογή για μηνιαίο πλάνο φαγητού και λίστα αγορών, με live συγχρονισμό μεταξύ συσκευών.

Κατάσταση: σε ανάπτυξη · https://naskal.github.io/meal-planner/

Σχεδιασμός και αποφάσεις: [docs/PROJECT-BRIEF.md](docs/PROJECT-BRIEF.md)

## Ανάπτυξη

```
npm install
npm run dev       # τοπικά
npm run deploy    # build και δημοσίευση στο GitHub Pages
```

Το αρχικό μονό αρχείο της εφαρμογής βρίσκεται στο `legacy/index.html`.
